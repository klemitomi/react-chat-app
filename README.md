# React Chat Application

A real-time chat application built with React, and CSS, Bootstrap.

## Features

- Real-time messaging
- User authentication (Google login)
- Responsive design
- Typing indicators
- Online status tracking

## Prerequisites

- Node.js (v16 or higher)
- npm or yarn
- Firebase project (for backend services)

## Project Structure

react-chat-app/
├── frontend/ # Frontend (React)
├── backend/ # Backend (Node.Js)
└── README.md


## Setup Instructions

### 1. Clone the repository

```bash
git clone https://github.com/klemitomi/react-chat-app.git
cd react-chat-app

```

### 2. Run Node backend server

```bash
cd react-chat-app
cd backend
npm install
node index.js
```

### 3. Run frontend

```bash
cd react-chat-app
cd frontend
npm install
npm run dev
```

### 4. Run Agent platform
typing in the browser http://localhost:5173/agent
then add the user, and password (from the {}agents.json)
